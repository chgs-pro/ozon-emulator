# История изменений

Версии нумеруются по [семантическому версионированию](https://semver.org/lang/ru/):

- **мажорная** (2.0.0) — несовместимые изменения: удалён метод, изменились формат конфигурации кабинета,
  управляющих событий или поведение, на которое опирается клиент;
- **минорная** (1.1.0) — новые методы Seller API и возможности, прежние сценарии работают как раньше;
- **патч** (1.0.1) — исправления ошибок и документации.

## [1.0.0] — 2026-09-25

Первая публичная версия.

- Тестовые кабинеты: ключи API из CLI, конфигурация из JSON, собственные часы кабинета, искусственные сбои
  429/503/504, управляющие события, хранение в MongoDB.
- Проверка запросов и ответов по описанию Seller API из SDK `phpsoftbox/ozon` — 87 методов.
- Товары и каталог: список и информация о товарах, дерево категорий, атрибуты, габариты.
- FBO: создание поставок DIRECT, CROSSDOCK, MULTI_CLUSTER; грузоместа и ТГМ, этикетки, изменение состава и слота,
  машина, отмена, приёмка и акты.
- FBS: склады продавца с асинхронным созданием, остатки, генерация тестовых заказов, отмена, требования
  и экземпляры («Честный ЗНАК», страна, ГТД, РНПТ, вес, IMEI, УИН), сборка с разделением, этикетки.

[1.0.0]: https://github.com/chgs-pro/ozon-emulator/releases/tag/v1.0.0

# Каталог: категории, атрибуты и характеристики товаров

Методы каталога позволяют загрузить из «Ozon» дерево категорий, атрибуты и характеристики товаров:
категорию, тип, габариты, вес и значения атрибутов. Они доступны любому кабинету и только читают данные.

| Метод | Что возвращает |
| --- | --- |
| `/v1/description-category/tree` | Дерево категорий из `catalog.categories`; типы товаров — дочерние элементы своей категории, как в Ozon |
| `/v1/description-category/attribute` | Атрибуты типа по паре `description_category_id` + `type_id`; тип из чужой категории — 404 |
| `/v4/product/info/attributes` | Товары кабинета: категория, тип, габариты с единицами измерения, значения атрибутов. Фильтры `product_id`, `offer_id`, `sku`; `limit` от 1 до 1000 (по умолчанию 100), продолжение — по `last_id` |

Кроме того, `/v3/product/info/list` отдаёт `description_category_id` и `type_id` товара.

## Настройка

Раздел `catalog` и характеристики товаров в конфигурации кабинета необязательны. Без них дерево пустое, а у товаров
нулевые категория, тип и габариты. В готовых наборах `fixtures/*.json` есть футболки (product_id 810001–810005)
и кружки (810006–810010); у 810006 габариты заданы в сантиметрах и килограммах.

```json
"catalog": {
  "categories": [
    {"id": 17027484, "name": "Одежда", "children": [
      {"id": 17028922, "name": "Футболки и топы", "types": [
        {"id": 92851, "name": "Футболка", "attributeIds": [85, 10096]}
      ]}
    ]}
  ],
  "attributes": [
    {"id": 85, "name": "Бренд", "type": "String", "isCollection": false, "dictionaryId": 28732849},
    {"id": 10096, "name": "Цвет товара", "isCollection": true}
  ]
}
```

Характеристики товара в `products`:

- `descriptionCategoryId` и `typeId` — категория и тип из дерева, задаются вместе;
- `dimensions` — целые `height`, `width`, `depth`, `weight` не меньше 0; `unit` — `mm`, `cm` или `in`;
  `weightUnit` — `g`, `kg` или `lb`;
- `attributes` — значения атрибутов своего типа: `[{"id": 85, "values": ["Бренд"]}]`.

При загрузке конфигурации проверяется, что ID категорий и атрибутов уникальны, у типов указаны известные атрибуты,
а у товара — существующая пара категории и типа.

## Упрощения

- Атрибуты не словарные: `dictionary_value_id` всегда 0.
- Обязательность атрибутов (`is_required`), группы и сложные атрибуты не моделируются.
